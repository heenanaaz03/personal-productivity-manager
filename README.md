# Personal Productivity Manager

A command-line productivity manager built with Python and Object-Oriented Programming (OOP).

## Features

- Add tasks with a title, description, deadline, and priority.
- View all tasks.
- Mark tasks as completed.
- Filter tasks by completion status.
- Identify overdue and upcoming deadlines.
- Save and load tasks using CSV file handling.
- Validate user input and handle common errors.

## Concepts Used

- Classes and objects
- Lists and loops
- Functions and methods
- Conditional statements
- Exception handling
- File handling with CSV
- Date and time operations

## How to Run

1. Install Python 3 if it isn't already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python main.py`
